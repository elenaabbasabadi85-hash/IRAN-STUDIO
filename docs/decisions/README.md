# یادداشت‌های تصمیم

هر یادداشت یک تصمیم مهم ایران استودیو را کوتاه توضیح می‌دهد: چه تصمیمی گرفتیم، چرا، و چه گزینه‌های دیگری بود. همه‌چیز از کد، ایشوها و درخواست‌های ادغام آمده است و هر یادداشت به منبعش پیوند دارد. اگر دلیلی جایی نوشته نشده بود، یادداشت همین را می‌گوید.

## یادداشت تازه

برای تصمیم تازه، یک فایل با شماره‌ی بعدی بساز، مثلاً `0009-short-name.md`، و این چهار بخش را بنویس: تصمیم، چرا، گزینه‌های دیگر، و از کجا آمده. بعد یک خط به همین جدول اضافه کن.
