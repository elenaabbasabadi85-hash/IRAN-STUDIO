# ایران استودیو

**خام بده، آماده ببر.**

ایران استودیو یک وب‌اپ فارسی و راست‌به‌چپ برای یوتیوبرهاست. کار را با یک ایده یا یک ویدیوی خام شروع می‌کنید و قدم‌به‌قدم جلو می‌روید: ایده، متن، ضبط و تدوین، و در آخر بستهٔ انتشار، یعنی عنوان، متن کاور، توضیحات و هشتگ‌ها.

- همهٔ کارهای ویدیویی در خود مرورگر انجام می‌شود.
- پروژه‌ها در مرورگر شما ذخیره می‌شوند. پایگاه داده و ورود به حساب نداریم.
- بدون هیچ کلید API هم کار می‌کند (حالت نمایشی، با فایل‌های نمونه).

این پروژه در حال ساخت است.

## تیم

| نام | مسیر کاری | مسئولیت |
| --- | --- | --- |
| محبوبه | پلتفرم | ظاهر و اجزای رابط کاربری، ذخیره‌سازی، متن‌های فارسی رابط، صفحهٔ اصلی و قیمت‌ها، ساخت پروژه، بستهٔ انتشار، مستندات و تنظیمات |
| النا | ویدیو | ضبط، تدوین، تبدیل گفتار به متن، و آزمایشگاه ویدیو |
| علیرضا | محتوا | عامل‌های هوش مصنوعی، پرامپت‌ها، ابزارهای زبان فارسی، فایل‌های نمونه، ایده، متن، نوشتن و ترندها |

فهرست دقیق پوشه‌های هر مسیر در [AGENTS.md](AGENTS.md) آمده است. تغییر در `src/core` تأیید هر سه نفر را لازم دارد.

## اجرا روی کامپیوتر خودتان

به Node.js نسخهٔ 20.9 یا بالاتر نیاز دارید.

```bash
npm install
npm run dev
```

بعد نشانی http://localhost:3000 را در مرورگر باز کنید.

برای حالت نمایشی کلید API لازم نیست. اگر خواستید سرویس‌های واقعی را امتحان کنید، فایل `.env.example` را با نام `.env.local` کپی کنید و کلیدهای خودتان را در آن بنویسید. فایل `.env.local` هیچ‌وقت کامیت نمی‌شود.
